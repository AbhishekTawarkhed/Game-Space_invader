# Space Invaders 

A classic arcade-style **Space Invaders** game built with [Pygame](https://www.pygame.org/).  
The player controls a spaceship, shoots bullets to destroy enemies, and earns points until the enemies reach the bottom of the screen.

---

## Features
- Player spaceship with left/right movement
- Multiple enemies with randomized positions
- Bullet firing mechanics
- Collision detection between bullets and enemies
- Score tracking
- Background image and sound effects
- Game Over screen when enemies reach the player

---

## Installation
Clone the repository and set up the environment:

```bash
git clone https://github.com/AbhishekTawarkhed/Game-Space_invader.git
cd Game-Space_invader
python -m venv venv
source venv/bin/activate   # On Linux/Mac
venv\Scripts\activate      # On Windows
pip install -r requirements.txt
```

---

## Usage
Run the game with:

```bash
python main.py
```

### Controls
- **Left Arrow** → Move left  
- **Right Arrow** → Move right  
- **Spacebar** → Fire bullet  

---

## Assets
The game uses the following assets (make sure they are in your project folder):
- `background.png` → Background image
- `background.wav` → Background music
- `ufo.png` → Window icon
- `player.png` → Player spaceship
- `enemy.png` → Enemy sprite
- `bullet.png` → Bullet sprite
- `explosion.wav` → Sound effect for firing/explosion
